生活支援センター おたすけ　支援利用規約

（申請の手伝い・申請代行を含む）

※これはテンプレート（ひな形）です。公開前に、弁護士・行政書士等の専門家による確認を受けることを強くおすすめします。

※生活支援センター おたすけ は、個人が始めた任意団体です。国や横浜市などの行政機関・公的機関ではなく、弁護士・行政書士・社会保険労務士などの資格者の事務所でもありません。

この規約は、生活支援センター おたすけ（以下「当団体」といいます。）が行う支援を利用するときのルールを定めたものです。支援を利用する方は、この規約と「プライバシーポリシー」をよく読み、内容に同意したうえで利用してください。

■第1条（目的）

（かんたんに言うと：この規約は、おたすけの支援を安心して使ってもらうためのルールです。）

この規約は、当団体の支援の内容、利用のしかた、当団体と利用者がそれぞれ守ることを定め、利用者が安心して支援を受けられるようにすることを目的とします。

■第2条（言葉の意味）

（かんたんに言うと：この規約で使う言葉の意味です。）

1. 「利用者」とは、当団体の支援を申し込み、または利用する方をいいます。

2. 「保護者」とは、利用者が18歳未満の場合の親権者、未成年後見人その他の法定代理人をいいます。

3. 「支援」とは、第4条に定める当団体の活動をいいます。

4. 「申請」とは、利用者が国、都道府県、市区町村、学校、奨学金の実施団体などに対して行う、制度の利用の申込みや届出をいいます。

5. 「協力者」とは、当団体の活動を手伝う運営責任者以外の人（ボランティアなど）をいいます。

■第3条（運営者）

（かんたんに言うと：運営しているのは任意団体「おたすけ」で、責任者は当団体の代表者です。）

・名称：生活支援センター おたすけ（任意団体）

・運営責任者：代表者

・所在地：神奈川県横浜市（詳しい住所は、お問い合わせいただいた方にお知らせします。）

・連絡先：LINE公式アカウント（@243pjqfg）、メール muse-mkm8@muse.ai

■第4条（支援の内容）

（かんたんに言うと：行政の制度の紹介、日用品の提供、仕事や進路・家計の相談など、困っていることを一緒に考えます。相談は無料です。）

当団体は、次の支援を行います。

1. 行政の支援制度の紹介：利用者の状況をうかがい、使える可能性のある行政の制度（例：就学援助、高校生等への奨学給付金、大学等の授業料減免や給付型奨学金、ひとり親家庭への手当や医療費助成など）を調べて、わかりやすく説明します。申請書の書き方の説明、必要な書類の確認、窓口への同行など、申請者が自分で手続するための手伝いも行います（第9条）。第10条の条件をすべて満たす場合に限り、利用者が作成し署名した申請書類を窓口へ提出することがあります。お金をもらって申請を代行することはありません。

2. 日用品の提供：生活に必要な日用品が足りないとき、できる範囲でお渡しします。内容や受け取りの方法は、面談で相談して決めます。

3. 就業支援：仕事やアルバイトの探し方、応募の準備などについて、一緒に考えます。就職のあっせんや、労働条件についての法的な判断は行いません。

4. 進路相談：進学や進路の悩みを聞き、使える制度や相談窓口の情報を案内します。学校の先生に代わって進路を決めることはありません。

5. 家計相談：今月の支出や、これからかかるお金のことを、一緒に整理して考えます。これはお話を聞きながら整理する場であり、投資・借入れなどの助言や、法律・税務の判断は行いません。

6. その他の相談：上記以外の困りごとも、まずはお話を聞かせてください。当団体だけで抱え込まず、必要に応じて専門の窓口を紹介します。

■第5条（支援の範囲外のこと）

（かんたんに言うと：法律の争いごとの代理、お金の貸し借り、医療の診断などはできません。必要なときは専門の窓口を紹介します。）

当団体は、次のことは行いません。必要な場合は、専門の機関や資格者を紹介します。

1. 法律相談、相手との交渉の代理、裁判・調停の手続、行政に対する審査請求（不服申立て）の代理（→ 法テラス、弁護士会などを紹介します。）

2. 行政書士・社会保険労務士などの資格が必要な書類の作成や提出の代理

3. お金の貸付けや立替え、借金の保証人になること

4. 医療・心理の診断や治療

5. 緊急時の保護や見守り（→ 第17条を参照してください。）

6. 利用者の代わりに申請するかどうかを決めること、申請の内容を決めること

■第6条（利用できる方）

（かんたんに言うと：生活に困っている中学生〜大学生、学生を育てるひとり親家庭、子どもだけで暮らす家庭が対象です。住んでいる地域は問いませんが、会える範囲が限られることがあります。）

1. 支援を利用できるのは、次のいずれかにあてはまり、生活に困っている方です。

・中学生、高校生（高等専門学校・専修学校などを含みます。）、大学生（短期大学・大学院などを含みます。）

・学生を育てているひとり親家庭

・子どもだけで暮らしている世帯（18歳未満の方だけの世帯を含みます。）

2. 住んでいる地域は限定しませんが、対面の面談ができる場所・日時には限りがあります。遠方の方には、お住まいの地域の相談窓口を紹介することがあります。

3. 当団体の人員や体制により、支援をお引き受けできない場合や、お待ちいただく場合があります。

■第7条（利用の流れ）

（かんたんに言うと：LINE登録 → アンケート → 3日以内に面談の日程連絡 → 会って面談 → 同意書 → 支援、の順で進みます。）

1. 当団体のInstagram、X、チラシ、ホームページなどで活動を知った方は、LINE公式アカウント（@243pjqfg）を友だち追加します。

2. LINEで案内するGoogleフォームの事前アンケートに回答します。

3. アンケートの回答から3日以内に、LINEでご連絡します。LINEを使えない方には、メールでご連絡します。

4. 第8条のルールに従って、対面で面談します。

5. 面談の内容をもとに、当団体が支援の内容を説明します。利用者（18歳未満の場合は原則として保護者も）が「支援利用の同意書」（様式2）に記入して、支援が始まります。

6. 申請の代行を利用する場合は、申請ごとに「申請代行の委任状」（様式1）を作成します。

7. 支援が終わったときは、その旨をお知らせします。

■第8条（面談のルール）

（かんたんに言うと：面談は対面のみです（LINE通話や電話では行いません）。人目のある公共の場所で行い、18歳未満の人と会うときはスタッフ2人以上か保護者同席にします。日程の連絡はLINE公式かメールだけです。）

1. 面談は対面のみとし、LINE通話や電話による面談は行いません。面談は、公共施設（地区センター、コミュニティハウスなど）や、人目のある場所で行います。当団体のスタッフの自宅や車の中、利用者の自宅、カラオケなどの個室で、スタッフと利用者が2人きりになることはありません。ただし、利用者が希望し、2人以上のスタッフで訪問する場合はこの限りではありません。

2. 利用者が18歳未満の場合は、当団体のスタッフ2人以上で対応するか、保護者など利用者が信頼する大人に同席してもらいます。

3. 面談の日時は、LINEで個別に決めます。所要時間は1回30分くらいです。場所は、地区センターなどの公共の場所です。

4. 利用者は、家族や友人、学校の先生など、信頼できる人と一緒に来ることができます。

5. 当団体は、面談の内容を記録します。録音は、利用者の同意がある場合に限り行います。利用者が面談を録音・撮影したい場合も、事前に相談してください。

6. 当団体と利用者の連絡は、LINE公式アカウントと当団体のメール muse-mkm8@muse.ai だけで行います。スタッフ個人の電話番号、個人のLINE、SNSアカウントで連絡をとることはありません。

7. 面談に来られなくなったときは、できるだけ早くLINE公式アカウントで連絡してください。

8. 面談場所までの交通費は、個別に相談して決めます。

■第9条（申請書類の作成の手伝い）

（かんたんに言うと：申請書はあなた（または保護者）が自分で書きます。おたすけは書き方を教えたり、確認したりします。）

2. 当団体は、制度の説明、記入方法の一般的な説明、必要書類の案内、申請者が記入した内容に記入もれがないかの確認など、申請者が自分で作成するための手伝いを行います。

3. 当団体は、申請書類を申請者に代わって作成（代筆・入力の代行を含みます。）しません。字を書くことが難しいなどの事情がある場合は、申請先の窓口が行う支援を利用できるよう案内します。

4. 申請するかどうか、どの制度に申請するか、何を書くかは、申請者が決めます。

5. 申請書類への署名・押印は、必ず申請者本人が行います。

■第10条（申請の代行の条件）

（かんたんに言うと：あなたが書いて署名した書類を、委任状をもらったうえで、おたすけが窓口に届けることがあります。お金や通帳・カードは預かりません。結果（通るかどうか）は約束できません。）

当団体が申請の代行（申請書類の提出や窓口とのやりとりの取次ぎ）を行うのは、次の条件をすべて満たす場合に限ります。

1. 申請者から、申請ごとに書面の委任状（様式1）を受け取っていること。申請者が18歳未満の場合は、保護者の同意があること（保護者がいないなどの事情がある場合は、事前に申請先の窓口や専門家に相談します。）。

2. 申請先が、代理人や使者による提出を認めていること。

3. 申請書類は申請者が自分で作成し、署名・押印していること。当団体は、受け取った書類の内容を書き換えません。

4. 提出前に申請者と一緒に内容を確認し、提出後は控えや受付の記録を申請者に渡すこと。

5. 窓口から書類の不足や修正の連絡があったときは、当団体は申請者に伝えるだけで、内容の修正は申請者が行うこと。

6. 当団体は、現金、通帳、キャッシュカード、クレジットカード、印鑑、暗証番号、パスワード、マイナンバーカード、マイナンバーが書かれた書類の写しを預かりません。給付金などは、必ず申請者本人（または保護者）名義の口座で受け取ってください。

7. 申請の代行は無償で行い、名目（手数料、会費、謝礼、寄付など）を問わず、対価を受け取らないこと。

8. 審査請求（不服申立て）や、行政機関との争いになっている事項の代理は行わないこと。

9. 申請者は、いつでも委任をやめることができること。

10. 当団体は、申請の結果（審査に通ること、給付の金額や時期など）を保証しません。審査は申請先が行います。

11. 申請の期限を守る責任は申請者にあります。当団体も期限をお知らせするよう努めます。

■第11条（料金）

（かんたんに言うと：支援の料金は無料です。申請書の手伝いや提出の代行で、お金や謝礼を受け取ることはありません。）

1. 当団体の支援の利用料金は、無料とします。名目（手数料、会費、謝礼、寄付など）を問わず、対価を受け取りません。

2. 前項の定めにかかわらず、申請書類の作成の手伝い（第9条）と申請の代行（第10条）については、名目を問わず一切の対価を受け取りません。

4. 利用者が当団体に寄付をするかどうかは、支援の利用とは関係がありません。寄付をしないことで支援の内容が変わることはありません。

■第12条（利用者にお願いすること）

（かんたんに言うと：正しい情報を伝えてください。うその申請には協力できません。）

1. 利用者は、当団体と申請先に、正しい情報を伝えてください。

2. 当団体は、事実と違う内容での申請や、制度の不正な利用に協力しません。

3. 住所・連絡先・家庭の状況などが変わったときは、当団体に知らせてください。

5. スタッフ・協力者に個人的な連絡先を求めたり、金品を渡したりすること

■第14条（当団体の約束）

（かんたんに言うと：おたすけのスタッフも、お金を受け取らない、個人的に連絡しない、勧誘しないなどのルールを守ります。）

5. 利用者の考えや決定を尊重し、申請を無理にすすめたり、やめさせたりしません。

3. 当団体の故意または過失により利用者に損害が生じた場合は、法令に従って責任を負います。

■第17条（緊急のとき）

（かんたんに言うと：命が危ないときは、すぐに110番・119番に電話してください。おたすけは緊急対応の機関ではありません。）

1. 当団体は、緊急時に保護や対応を行う機関ではありません。LINEやメールへの返信には時間がかかることがあります。

2. 命の危険があるときや、事件・事故・急病のときは、すぐに警察（110番）や救急（119番）に連絡してください。

3. 虐待を受けている、家にいるのが危ないなどの場合は、児童相談所虐待対応ダイヤル（189番）に連絡できます。

4. 当団体は、利用者や周りの人の命や安全を守るために必要な場合、児童虐待が疑われる場合などは、プライバシーポリシーに従い、関係機関に連絡します。

■第18条（支援の中止・終了）

（かんたんに言うと：あなたはいつでも支援をやめられます。ルールを守ってもらえない場合などは、おたすけから支援を終わりにすることもあります。）

1. 利用者は、いつでも、理由を言わずに支援の利用をやめることができます。LINE公式アカウントまたはメールで知らせてください。

2. 当団体は、次の場合に、支援を中止または終了することがあります。

・支援の目的が達成されたとき

・利用者が第13条の禁止事項にあたる行為をしたとき

・1か月以上、利用者と連絡がとれないとき

・利用者の困りごとが当団体の支援の範囲を超え、ほかの機関で支援を受けるほうがよいと判断したとき

・当団体の活動の継続が難しくなったとき

3. 当団体から支援を終了するときは、できる限り事前にその理由を伝え、必要に応じてほかの相談先を紹介します。

4. 支援が終わった後の個人情報は、プライバシーポリシーに従って保存・廃棄します。

■第19条（規約の変更）

（かんたんに言うと：ルールを変えるときは、前もってホームページやLINEでお知らせします。）

1. 当団体は、法令の改正や活動内容の変化に合わせて、この規約を変更することがあります。

2. 変更するときは、変更の内容と開始日を、ホームページ・LINE公式アカウントなどで事前にお知らせします。

3. 利用者にとって重要な変更（料金を有料にする場合など）は、改めて利用者の同意を得ます。

■第20条（準拠法・話し合いによる解決）

（かんたんに言うと：この規約は日本の法律に従います。困ったことは、まず話し合って解決します。）
