生活支援センター おたすけ　プライバシーポリシー

■第2条（言葉の意味）

（かんたんに言うと：このポリシーで使うむずかしい言葉の意味を説明しています。）

1. 「個人情報」とは、生きている個人に関する情報で、名前や生年月日などにより、その人がだれかが分かるものをいいます。ほかの情報と簡単に照らし合わせて、だれかが分かるものも含みます。

2. 「要配慮個人情報」とは、病気や障害、犯罪の被害にあったことなど、知られると差別や不利益につながるおそれがあるため、法律で特に慎重な扱いが求められている情報をいいます。

3. 「本人」とは、その個人情報で特定される方をいいます。

4. 「保護者」とは、本人が18歳未満の場合の親権者、未成年後見人その他の法定代理人をいいます。

■第3条（当団体が取得する情報）

（かんたんに言うと：LINE、フォーム、面談などで、支援に必要な情報を受け取ります。）

当団体は、支援に必要な範囲で、次の情報を取得します。

1. LINE公式アカウントから取得する情報：LINEの表示名、プロフィール画像、ステータスメッセージ、当団体とのトークの内容（送られた画像・ファイルを含みます。）、友だち追加・ブロックの日時など、LINE公式アカウントの機能により当団体が見ることのできる情報

2. Googleフォーム（事前アンケート）の回答：氏名、ふりがな、年齢・生年月日、学校名・学年、住所（市区町村など）、電話番号・メールアドレス、世帯の構成、困っていること、収入や支出・仕送り・奨学金などの家計の状況、利用している制度、健康や障害に関すること（回答は任意です。）、面談の希望日時、フォームの設定によってはGoogleアカウントのメールアドレス

3. 面談で取得する情報：相談の内容、家庭の状況、学校生活の状況、面談の記録（メモ）、本人の同意がある場合の録音

4. 支援の中で取得する情報：申請書類の写しや控え、制度の利用状況や審査の結果、関係機関とのやりとりの記録、委任状・同意書の内容

5. メール、SNS（Instagram・X）のメッセージ、ホームページの問い合わせで送られた情報

6. 当団体は、マイナンバー（個人番号）を集めたり、保管したりしません。マイナンバーが書かれた書類を見せていただく場合も、写しは取りません。

■第4条（要配慮個人情報について）

（かんたんに言うと：病気・障害・被害などのとても大事な情報は、あなたの同意をもらってから受け取り、特に気をつけて扱います。話したくないことは話さなくて大丈夫です。）

1. 支援の内容によっては、病歴・障害・心身の状態、犯罪の被害にあった事実など、要配慮個人情報にあたる情報をうかがうことがあります。

2. 当団体は、法令で認められた場合を除き、あらかじめ本人（本人が18歳未満の場合は、第12条のとおり保護者を含みます。）の同意を得てから要配慮個人情報を取得します。

3. 収入、借金、家族の関係、生活の状況などは、法律上の要配慮個人情報にあたらない場合でも、要配慮個人情報と同じように慎重に取り扱います。

4. 答えたくない質問には、答えなくてかまいません。答えないことで不利な扱いをすることはありません。ただし、情報が足りないと、使える制度を案内できない場合があります。

■第5条（利用目的）

（かんたんに言うと：あなたの情報は、あなたを支援するためだけに使います。）

当団体は、取得した個人情報を次の目的のためだけに利用します。

1. 相談の受付、本人確認、面談日程の調整と連絡のため

2. 本人に合う支援制度を調べ、案内するため

3. 申請書類の作成の手伝い、本人の依頼にもとづく申請手続の手伝いのため

4. 行政機関・学校・食料支援団体などへのつなぎのため（第7条のとおり、原則として本人の同意を得て行います。）

5. 支援の記録をつくり、継続して支援するため

6. 本人の生命・身体の安全を守るため

7. 支援の質を良くするための振り返り、活動報告や助成金の報告のための統計づくり（この場合は、だれのことか分からない形にして使います。）

8. お問い合わせへの回答のため

上記以外の目的で使う必要が出てきたときは、法令で認められた場合を除き、あらかじめ本人の同意を得ます。

■第6条（情報の取得のしかた）

（かんたんに言うと：うそをついたり、だましたりして情報を集めることはしません。）

1. 当団体は、適正な方法で、原則として本人（または保護者）から直接、個人情報を取得します。

2. 学校、行政機関、ほかの支援団体などから紹介を受ける場合は、紹介元が本人の同意を得ていることを確認します。

■第7条（第三者への提供）

（かんたんに言うと：あなたの情報を他の人や機関に伝えるのは、原則としてあなたが「いいよ」と言ったときだけです。ただし、命や安全を守るためなど、法律で決められた例外があります。）

1. 当団体は、次項の場合を除き、あらかじめ本人の同意を得ないで、個人情報を第三者に提供しません。

2. 支援のために、次のような機関・団体に情報を伝える必要があるときは、だれに、どの情報を、何のために伝えるのかを事前に説明し、本人（必要な場合は保護者）の同意を得てから、必要最小限の情報だけを伝えます。

・市区町村役所（区役所の担当課など）、福祉事務所、こども家庭センターなどの行政機関

・本人が通っている学校（担任、スクールソーシャルワーカー、奨学金の担当窓口など）

・社会福祉協議会、フードバンク・フードパントリー、子ども食堂などの支援団体

・その他、本人が希望する機関

3. 次の場合は、法令にもとづき、本人の同意を得ないで情報を提供することがあります（個人情報保護法第27条第1項）。

・法令にもとづく場合（児童虐待を受けたと思われる子どもを見つけた場合の、市町村・児童相談所などへの通告を含みます。）

・人の生命、身体または財産を守るために必要で、本人の同意を得ることが難しい場合（例：命の危険がある、大けがや病気で急いで助けが必要など）

・子どもの健やかな成長のために特に必要で、本人の同意を得ることが難しい場合

・国や地方公共団体などが法令で決められた仕事をすることに協力する必要があり、本人の同意を得るとその仕事に支障が出るおそれがある場合

4. 児童虐待の通告は、法律で決められた義務です（児童虐待の防止等に関する法律第6条）。この場合、当団体の秘密を守る約束よりも通告が優先されます。通告するときも、できる限り本人の気持ちを聞き、本人の安全を第一に考えます。

5. 第三者に提供したときは、法令に従って記録を作成し、保存します。

■第8条（外部サービスの利用と委託）

（かんたんに言うと：LINEやGoogleのサービスを使って連絡や記録をしています。それぞれの会社のルールも確認してください。）

1. 当団体は、活動のために次の外部サービスを利用しており、個人情報はこれらのサービス上で保管・処理されます。

・LINEヤフー株式会社が提供する「LINE公式アカウント」（連絡、予約、お知らせのため）

・Google LLCが提供する「Googleフォーム」「Googleスプレッドシート」「Googleドライブ」「Gmail」など（アンケート、記録の保管、メール連絡のため）

2. これらのサービスでは、日本国外（アメリカ合衆国など）のサーバーに情報が保存される場合があります。各国の個人情報の保護に関する制度については、個人情報保護委員会のホームページなどで確認し、必要な安全管理措置をとります。

3. 各サービスにおける情報の取扱いは、各社のプライバシーポリシーに従います。

・LINEヤフー株式会社 プライバシーポリシー：https://www.lycorp.co.jp/ja/company/privacypolicy/

・Google プライバシーポリシー：https://policies.google.com/privacy?hl=ja

4. 個人情報の取扱いをほかの人や事業者に任せる（委託する）ときは、安全に取り扱われるよう、相手を選び、契約を結び、必要な監督を行います（個人情報保護法第25条）。

5. 当団体の活動を手伝う協力者（ボランティアなど）が個人情報を扱う場合は、事前に秘密を守ることを書面で約束してもらい、必要な範囲の情報だけを扱わせます。

■第9条（安全管理のための取組み）

（かんたんに言うと：あなたの情報がもれたり、なくなったりしないように、しっかり管理します。）

当団体は、個人情報がもれたり、なくなったり、こわれたりしないよう、次のような対策をとります（個人情報保護法第23条）。

1. 組織的な対策：運営責任者を個人情報の管理者とし、情報を扱える人を必要最小限に限ります。取扱いのルールを決め、定期的に点検します。

2. 人的な対策：協力者には秘密を守る誓約をしてもらい、個人情報の扱い方を説明します。活動をやめた後も秘密を守ってもらいます。

3. 物理的な対策：紙の書類は鍵のかかる場所に保管し、必要なとき以外は持ち出しません。面談の場所では、書類や画面をほかの人に見られないよう気をつけます。

4. 技術的な対策：支援専用のアカウントと端末を使い、パスワードと2段階認証を設定します。ファイルの共有範囲を限り、個人のSNSやLINEアカウントでは相談のやりとりをしません。

5. 外国の制度の把握：日本国外のサーバーを使う場合は、その国の制度を把握したうえで管理します。

6. もし情報がもれるなどの事故が起きたときは、すぐに被害が広がらないよう対応し、法令に従って本人への連絡と個人情報保護委員会への報告を行います。

■第10条（保存期間と廃棄）

（かんたんに言うと：情報は決められた期間だけ保管し、いらなくなったら安全な方法で消します。）

1. 当団体は、個人情報を、支援が終わった日（最後に連絡をとった日）から【◯年】保存します。

2. 支援につながらなかった方の事前アンケートの回答は、回答日から【◯年】で削除します。

3. 保存期間が過ぎた情報は、紙はシュレッダー等で読めない状態にして廃棄し、データは復元できない方法で削除します。

4. 本人から削除の希望があったときは、法令で保存が必要な記録などを除き、保存期間内であっても削除します。

5. LINEのトーク履歴は、LINE公式アカウントの機能や仕様により、当団体が完全に削除できない場合があります。

■第11条（開示・訂正・利用停止などのご請求）

（かんたんに言うと：「自分のどんな情報を持っているか見せてほしい」「まちがいを直してほしい」「使うのをやめてほしい」と、いつでもお願いできます。）

1. 本人は、当団体に対して、次のことを請求できます（個人情報保護法第32条から第35条まで）。

・利用目的の通知

・保有している個人情報の開示（見せること）

・内容がまちがっている場合の訂正・追加・削除

・利用の停止・消去

・第三者への提供の停止

・第三者に提供した記録の開示

2. 請求は、LINE公式アカウントまたはメール【メールアドレス】で受け付けます。

3. ほかの人による「なりすまし」を防ぐため、本人であることを確認させていただきます。保護者や、本人から頼まれた代理人も請求できます。その場合は、代理の権限を確認します。

4. 手数料はいただきません。

5. 請求を受けたときは、遅滞なく対応し、結果をお知らせします。法令によりお応えできない場合は、その理由をお伝えします。

■第12条（18歳未満の方の情報）

（かんたんに言うと：18歳未満の人は、原則として保護者の同意をもらいます。でも、保護者がいない・連絡できない・保護者に知られると危ないときは、あなたの安全を一番に考えて対応します。）

1. 本人が18歳未満の場合、当団体は、原則として保護者の同意を得たうえで、個人情報を取得・利用し、第三者に提供します。保護者には、本人の年齢や理解に合わせて説明します。

2. 本人自身にも、年齢や理解の程度に合わせて分かりやすく説明し、本人の意見を大切にします。

3. 次のような場合は、保護者の同意を得ずに支援を始めることがあります。

・保護者がいない、または保護者と連絡がとれない場合

・保護者に知らせると、本人の心や体の安全が損なわれるおそれがある場合（虐待の疑いがある場合など）

・保護者が同意しないものの、本人の生命・身体の保護や健やかな成長のために支援が特に必要な場合

4. 前項の場合、当団体は、本人の同意を得たうえで、必要最小限の情報を使い、まず区役所・児童相談所・学校などの公的な相談先へつなぐことを基本とします。当団体だけで判断せず、2人以上で確認し、判断の理由を記録します。

5. 第7条第3項の場合（命や安全を守るために急ぐ場合や、児童虐待の通告など）は、本人と保護者の同意がなくても、関係機関に情報を伝えることがあります。

6. 18歳以上の方（大学生など）の情報は、本人の同意がない限り、保護者を含む家族に伝えません。

7. 法律の改正により、16歳未満の方の情報の取扱いについて新しいルールが定められる予定です。施行された場合は、それに従ってこのポリシーを見直します。
